📋 AVAILABLE COMMANDS:


   omnisystem gui              Launch CLI App Menu (displays in terminal)
   omnisystem app-menu         Alias for gui
   omnisystem titan <ARGS>     Run TITAN compiler (Systems Language)
   omnisystem sylva <ARGS>     Run SYLVA compiler (AI/ML Language)
   omnisystem aether <ARGS>    Run AETHER compiler (Distributed Systems)
   omnisystem axiom <ARGS>     Run AXIOM compiler (Formal Verification)
   omnisystem --version        Show version
   omnisystem --help           Show help
