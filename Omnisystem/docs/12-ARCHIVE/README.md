## Getting Started

### 1. Installation
```bash
# Clone the repository
git clone https://github.com/omnisystem/omnisystem.git
cd omnisystem

# Build the system
cargo build --release

# Run tests
cargo test --all
```

### 2. Create Your First Program
```titan
// hello.titan
fn main() {
    println!("Hello from Omnisystem!");
}
```

### 3. Run Your Program
```bash
omni run hello.titan
```
