# Omnisystem Code of Conduct

## Our Commitment

The Omnisystem community is committed to providing a safe, inclusive, and welcoming environment for all people, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

We are dedicated to fostering a community where all individuals can:
- **Participate openly** - Share ideas and contribute meaningfully
- **Feel welcome** - Be accepted for who they are
- **Work effectively** - Collaborate without fear or harassment
- **Grow professionally** - Learn and develop new skills
- **Enjoy themselves** - Have fun building great software

---

## Our Standards

### Positive Behaviors

Examples of behavior that contribute to a positive environment include:

- **Being respectful** - Value differing opinions and experiences
- **Being inclusive** - Welcome people of all backgrounds
- **Being collaborative** - Work together constructively
- **Being patient** - Give others time to understand
- **Giving feedback** - Provide constructive criticism kindly
- **Being accountable** - Take responsibility for mistakes
- **Helping others** - Support community members
- **Celebrating diversity** - Recognize and value differences
- **Leading by example** - Demonstrate the behavior you expect

### Unacceptable Behavior

Examples of unacceptable behavior include:

- **Harassment** - Unwanted or offensive comments, messages, or actions
- **Discrimination** - Treating someone unfairly based on protected characteristics
- **Hate speech** - Content that demeans or attacks individuals or groups
- **Bullying** - Aggressive behavior intended to harm or intimidate
- **Doxxing** - Sharing private information without consent
- **Sexual harassment** - Unwelcome sexual comments or advances
- **Trolling** - Intentionally disruptive or inflammatory messages
- **Threats** - Threats of violence or harm
- **Abuse** - Any form of abuse or mistreatment
- **Spam** - Unsolicited or repetitive messages

---

## Scope

This Code of Conduct applies to:

- **All spaces** - GitHub issues, pull requests, discussions, code reviews
- **Official channels** - Discord, forums, mailing lists, events
- **Community interactions** - Any interaction related to Omnisystem
- **Public representation** - Speaking about the project publicly
- **Leadership** - Maintainers and core team members are held to higher standards

---

## Enforcement

### Reporting Violations

If you witness or experience a violation of this Code of Conduct:

1. **Document the incident** - Note details, timestamps, usernames
2. **Report to moderators** - Contact a maintainer directly
3. **Email us** - conduct@omnisystem.io (private)
4. **Provide context** - Explain what happened and why it's problematic

**All reports will be handled confidentially.**

### Reporting Template

```
Subject: Code of Conduct Violation Report

Date of Incident: [date]
Location: [GitHub issue #, Discord channel, etc.]
Reported User: [username]

Description:
[What happened? Be specific and factual.]

Links/Evidence:
[Screenshots, links to messages, etc.]

Impact:
[How did this affect you or others?]

Your Contact:
[How can we reach you for follow-up?]
```

### Investigation Process

1. **Acknowledgment** - We'll confirm receipt within 48 hours
2. **Investigation** - Review the incident and gather information
3. **Decision** - Determine appropriate action
4. **Notification** - Inform relevant parties of the outcome
5. **Appeal** - Provide a process for appeal if needed

### Response Levels

**Warning** - First minor violation
- Private message to the person
- Explanation of the issue
- Clear expectations going forward

**Temporary Ban** - Repeated violations or serious infractions
- Suspension from community for 7-30 days
- Requirement for discussion before return
- Monitoring upon return

**Permanent Ban** - Egregious violations or pattern of behavior
- Permanent removal from the community
- No further participation
- No appeal

## Examples

### Example 1: Respectful Disagreement ✅

```
GitHub Comment:
"I disagree with this approach. Here's why:

1. It doesn't handle edge case X
2. Performance could be better with Y
3. Have you considered Z?

Happy to discuss alternatives!"
```

**✅ This is good:** Respectful, constructive, focused on ideas.

### Example 2: Disrespectful Disagreement ❌

```
GitHub Comment:
"This is stupid. You clearly don't understand anything.
Anyone with a brain would do it differently."
```

**❌ This violates the Code of Conduct:** Attacking the person, not the idea.

### Example 3: Helpful Review ✅

```
GitHub Review Comment:
"Great start! A few suggestions:
- Consider using the existing utility function X
- This could have a memory leak if Y happens
- The test for Z is missing

Let me know if you'd like help with any of these!"
```

**✅ This is good:** Constructive, supportive, actionable.

### Example 4: Condescending Review ❌

```
GitHub Review Comment:
"Did you even read the documentation? This is basic stuff.
Your variable names are terrible. Why would anyone do this?"
```

**❌ This violates the Code of Conduct:** Condescending and insulting.

### Example 5: Welcoming New Contributor ✅

```
GitHub Issue Comment:
"Welcome to the project! Great first issue to work on.

Here are some resources:
- [Architecture guide](link)
- [Similar past PR](link)

Feel free to ask questions if you get stuck!"
```

**✅ This is good:** Welcoming, supportive, helpful resources.

### Example 6: Gatekeeping ❌

```
GitHub Issue Comment:
"This project isn't for beginners. Go learn the basics first
before wasting our time with trivial contributions."
```

**❌ This violates the Code of Conduct:** Exclusionary and discouraging.

## Responsibilities

### All Community Members

- Follow this Code of Conduct
- Be respectful and inclusive
- Report violations
- Stand up against harassment
- Welcome new contributors

### Maintainers

- Enforce this Code of Conduct
- Respond promptly to reports
- Make fair, impartial decisions
- Be transparent about outcomes
- Lead by example
- Recuse themselves from cases involving conflicts of interest

### Moderators

- Monitor community spaces
- Intervene in violations
- Support code of conduct enforcement
- Help resolve conflicts
- Create a welcoming environment

---

## Appeal Process

If you believe a decision was unfair:

1. **Wait 7 days** - Take time to reflect
2. **Request appeal** - Email conduct@omnisystem.io
3. **Submit statement** - Explain why you think the decision was unfair
4. **Review** - Independent reviewer will reconsider
5. **Decision** - Final ruling will be provided

Appeals should be made in good faith and with respect.
