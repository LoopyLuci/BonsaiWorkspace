## 📖 Documentation Standards

### File Organization
- **Location**: `/docs/` directory with logical subdirectories
- **Format**: Markdown with GitHub-flavored syntax
- **Naming**: Lowercase with underscores (e.g., `QUICK_START.md`)
- **Links**: Relative paths for internal documentation

### Content Requirements
- ✅ Clear, concise writing (active voice)
- ✅ Practical examples for all major features
- ✅ Code snippets in TITAN, Sylva, Aether, Axiom
- ✅ Diagrams and screenshots where helpful
- ✅ Table of contents for long documents
- ✅ "See also" references for related topics
- ✅ Last updated dates and version numbers

### Code Examples
- All code examples use Omnisystem languages (TITAN/SYLVA/AETHER/AXIOM)
- Examples are tested and verified
- Comments explain non-obvious code
- Copy-paste ready code blocks
