## 🎨 CUSTOMIZATION PROPERTIES

### Color System
- **Primary Color** - Main brand/accent color
- **Secondary Color** - Supporting color
- **Tertiary Color** - Additional color
- **Accent Color** - Highlight color
- **Background Color** - Main background
- **Surface Color** - Card/panel background
- **Error Color** - Error/destructive actions
- **Warning Color** - Warnings
- **Success Color** - Success states
- **Info Color** - Informational
- **Text Primary** - Main text
- **Text Secondary** - Secondary text
- **Border Color** - Borders/dividers
- **Disabled Color** - Disabled states

### Typography
- **Font Family** - Primary font (Inter, Roboto, etc.)
- **Heading Font** - Heading-specific font
- **Monospace Font** - Code/terminal font
- **Base Font Size** - Default size (12px-18px)
- **Heading Scale** - Ratio between heading sizes (1.2-2.0)
- **Line Height** - Text line spacing (1.2-1.8)
- **Letter Spacing** - Character spacing
- **Font Weight** - Boldness variations

### Component Style
- **Border Radius** - Corner roundness (0px-20px+)
- **Border Width** - Border thickness (0px-3px)
- **Shadow Depth** - Shadow intensity (0-5 levels)
- **Opacity** - Transparency levels
- **Spacing Scale** - Padding/margin scale (80%-120%)
- **Corner Style** - Sharp, rounded, smooth
- **Button Style** - Filled, outlined, elevated
- **Icon Style** - Outlined, filled, rounded

### Special Effects
- **Blur** - Backdrop blur amount
- **Glow** - Glow effects on elements
- **Gradient** - Background gradients
- **Animation** - Motion and transitions
- **Parallax** - Depth effects
- **Glassmorphism** - Frosted glass effects
- **Neumorphism** - Embossed effects
- **Animations Speed** - Fast, normal, slow

## 🎯 THEME GENERATION METHODS

### 1. **Color-Based Generation**
Input one color, generates entire theme:
- Monochromatic: Shades of base color
- Analogous: Similar colors on color wheel
- Complementary: Opposite colors
- Triadic: Three evenly-spaced colors
- Tetradic: Four colors in rectangle
- Split-Complementary: Base + two colors
- Square: Four colors equidistant

### 2. **Image-Based Generation**
Upload image, extract color palette:
- Dominant color extraction
- Palette generation from image
- Mood detection from image
- Automatic theme creation
- 5-10 theme variations

### 3. **Mood-Based Generation**
Describe feeling, generate theme:
- "Calm and professional" → Blue/gray palette
- "Energetic and fun" → Bright multicolor
- "Dark and mysterious" → Dark purples/blacks
- "Nature and organic" → Greens/browns
- "Tech and futuristic" → Neon/cyber colors

### 4. **Design System Generation**
Select design system, generate theme:
- Material Design → Complete Material theme
- Fluent Design → Microsoft aesthetic
- iOS Design → Apple aesthetic
- Bootstrap → Web standard colors
- Custom system → User-defined

### 5. **AI Procedural Generation**
Algorithm creates unique themes:
- Random but harmonious colors
- Respects color harmony rules
- Ensures accessibility
- Prevents clashing colors
- Generates thousands daily
