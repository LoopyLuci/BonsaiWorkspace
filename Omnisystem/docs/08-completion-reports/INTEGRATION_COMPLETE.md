## 🔄 How Communication Works

### Example: Web App Calling Backend Service

```
Web App (VERA) 
  → Connector Gateway (Universal)
  → Service Registry (discovers "backend_service" → TITAN)
  → Message Protocol (encapsulates request)
  → TITAN Service
  → Database Layer (via connector)
  → Result back through gateway
  → Rendered in VERA component
```

### Example: Mobile App Using Sensors

```
Mobile App (NEXUS)
  → NEXUS Sensor Manager
  → UOSC Input Drivers
  → Raw sensor data
  → Application processes via NEXUS bridge
  → Updates UI via widget system
```

### Example: Game Using ML

```
Game (HELIX)
  → Connector Gateway
  → SYLVA Service (get ML predictions)
  → Use results in game logic
  → Render via HELIX
  → Save state via AETHER
```

## 🚀 Next: Application Usage

### To Create a New Application:

1. **Use Template**
   ```ti
   import omnisystem.applications.template
   import omnisystem.modules.connector_gateway
   import omnisystem.ui.widget_system
   ```

2. **Initialize Core**
   ```ti
   let core = omnisystem::integration::init_omnisystem()?
   ```

3. **Access Services**
   ```ti
   core.connector_gateway.call_service("titan_service", "io_read", params)?
   ```

4. **Use Widgets**
   ```ti
   let button = widget_system::create_button("Click Me", on_click_handler)
   ```

5. **Deploy**
   - TITAN → Server
   - VERA → Web
   - HELIX → Graphics/Game
   - NEXUS → Mobile
