================================================================================
  BUILD OPTIONS AND FLAGS
================================================================================

COMMON OPTIONS:

  -Release          Build in Release mode (O3 optimization)
                    Default: Debug (O0, faster builds)
                    Time impact: +15%
                    Size impact: Slightly smaller executable
                    Use for: Production, performance testing

  -Clean            Clean build artifacts before compilation
                    Default: Incremental (use cache)
                    Time impact: Adds 30 seconds
                    Use when: After major changes, build corruption

  -Verbose          Enable detailed logging output
                    Default: Quiet (errors only)
                    Use for: Debugging, understanding build process

  -Launch           Launch application immediately after build
                    Default: Don't launch
                    Use for: Quick testing during development

  -SkipVerify       Skip post-build verification tests
                    Default: Run verification
                    Time impact: Saves ~30 seconds
                    Warning: May miss errors

  -Benchmark        Run performance benchmarks after build
                    Default: No benchmarking
                    Time impact: Adds 2-3 minutes
                    Use for: Performance analysis

  -GpuTarget nvidia Build NVIDIA GPU support only
           amd    Build AMD GPU support only
           intel  Build Intel GPU support only
           arm    Build ARM GPU support only
           all    Build all GPU vendors (default)
                    Default: all
                    Time impact: 30-40% faster with single target
                    Size impact: 20% smaller executable per vendor

COMBINATIONS:

  .\Build-Omnisystem-Launcher-Graphics.ps1 -Release -GpuTarget nvidia -Launch
  # Quick optimized build for NVIDIA, auto-launch

  .\Build-Omnisystem-Launcher-Graphics.ps1 -Clean -Verbose
  # Clean rebuild with detailed logging

  .\Build-Omnisystem-Launcher-Graphics.ps1 -Release -Benchmark
  # Optimized build with performance measurements

================================================================================
  ENVIRONMENT VARIABLES
================================================================================

COMPILER SETTINGS:

  TITAN_COMPILER_PATH        Path to Titan compiler executable
  TITAN_TARGET               Target platform (windows-x64, linux-x64, etc.)
  TITAN_OPTIMIZATION_LEVEL   O0, O1, O2, O3 (optimization level)
  TITAN_PARALLEL_JOBS        Number of parallel compilation jobs
  TITAN_CACHE_DIR            Build cache directory location
  TITAN_STRIP_SYMBOLS        true/false - remove debug symbols from exe
  TITAN_LTO                  true/false - enable link-time optimization

GPU SETTINGS:

  GRAPHICS_FORCE_VENDOR      Force specific GPU vendor (nvidia/amd/intel/arm)
  GRAPHICS_DEVICE_ID         Force specific GPU device index
  GRAPHICS_PREFER_DISCRETE   true/false - prefer discrete GPU
  GRAPHICS_FORCE_INTEGRATED  Force integrated GPU only
  GRAPHICS_DEBUG             true/false - enable debug logging
  GRAPHICS_LOG_LEVEL         DEBUG, INFO, WARN, ERROR
  GRAPHICS_ENABLE_PROFILING  true/false - collect profiling data

PERFORMANCE SETTINGS:

  GPU_MEMORY_BUDGET          Maximum GPU VRAM to use (MB)
  TARGET_FRAME_RATE          Target FPS (60, 120, 144, etc.)
  POWER_MODE                 performance, balanced, conservative
  RENDER_TARGET_WIDTH        Internal rendering width (pixels)
  RENDER_TARGET_HEIGHT       Internal rendering height (pixels)
  MAX_RENDER_CALLS_PER_FRAME Maximum draw calls per frame

EXAMPLE:

  $env:TITAN_PARALLEL_JOBS = "4"
  $env:GRAPHICS_DEBUG = "true"
  .\Build-Omnisystem-Launcher-Graphics.ps1

================================================================================
  COMMON ISSUES AND QUICK FIXES
================================================================================

Build doesn't start:
  1. Run: .\BUILD_VALIDATION_SCRIPT.ps1
  2. Check: Is Titan compiler installed?
  3. Check: PowerShell execution policy (7+)

Build is very slow:
  1. Check: Use SSD not HDD
  2. Enable: $env:TITAN_PARALLEL_JOBS = "4"
  3. Try: -GpuTarget nvidia (single GPU = smaller)

Build fails with "Out of memory":
  1. Close: Other heavy applications
  2. Reduce: $env:TITAN_PARALLEL_JOBS = "1"
  3. Try: -GpuTarget nvidia (smaller build)

GPU not detected:
  1. Check: Run: Get-CimInstance Win32_VideoController
  2. Update: GPU drivers (nvidia-smi, or manufacturer website)
  3. Check: BIOS - ensure GPU is enabled
  4. Verify: Device Manager shows GPU as working

Application won't launch:
  1. Try: Run with -Verbose flag to see errors
  2. Check: Visual C++ Runtime installed
  3. Check: DirectX installed (dxwebsetup.exe)
  4. Try: Different GPU driver version

Frame rate is low (< 30 FPS):
  1. Check: GPU in use (nvidia-smi or equivalent)
  2. Check: Temperature not throttling (nvidia-smi)
  3. Try: Reducing resolution
  4. Try: Rebuilding with single GPU target

Test failures:
  1. Check: BUILD_VALIDATION_SCRIPT.ps1 passes
  2. Check: Application can launch manually
  3. Check: GPU drivers updated
  4. Review: Test report in .test-logs directory

  ☐ PowerShell 7+ installed (powershell -Version)
  ☐ Titan compiler built (ls Omnisystem\titan_compiler\target\release)
  ☐ Visual C++ Runtime installed
  ☐ 10+ GB free disk space
  ☐ 4+ GB RAM available
  ☐ GPU drivers updated (nvidia-smi, etc.)

Before running:
  ☐ Executable exists (Omnisystem\launchers\Omnisystem_Graphics.exe)
  ☐ Executable size reasonable (5-20 MB)
  ☐ File timestamp recent (last hour)
  ☐ GPU detected (Get-CimInstance Win32_VideoController)
