HOW TO BUILD & RUN
==================

Prerequisites:
  - Rust toolchain (rustc, cargo)

Build:
  cd titan_compiler
  cargo build --release

Run REPL:
  cargo run -- repl

Run Example:
  cargo run -- run ../examples/hello_world.titan

Build Executable:
  cargo run -- build ../examples/fibonacci.titan

Generate LLVM IR:
  cargo run -- compile ../examples/functions.titan

COMPILATION PIPELINE
====================

1. Input: TITAN source code
2. Tokenization: Convert to tokens
3. Parsing: Build AST
4. Type Checking: Validate and analyze
5. Interpretation: Execute or compile
6. Output: Results, binary, or IR
