COMPILER ARCHITECTURE
═════════════════════════════════════════════════════════════════════════════════

Each language compiler follows the same proven architecture:

    Source Code (.titan, .sylva, .aether, .axiom files)
            ↓
    Lexer (Tokenization)
            ↓
    Parser (AST Construction)
            ↓
    Type Checker (Semantic Analysis)
            ↓
    Interpreter (Runtime Execution or Code Generation)
            ↓
    Output (Results, Binary, or Verification Report)

Standard Pipeline Features Implemented in All 4 Languages:
  ✅ Complete tokenization
  ✅ Full parsing with operator precedence
  ✅ Type inference and checking
  ✅ Scope management
  ✅ Error reporting with line/column info
  ✅ Interactive REPL for each language
  ✅ File-based program execution

HOW TO USE
═════════════════════════════════════════════════════════════════════════════════

1. Build All Languages:
   cd titan_compiler && cargo build --release && cd ../sylva_compiler && cargo build --release && cd ../aether_compiler && cargo build --release && cd ../axiom_compiler && cargo build --release

2. Run Individual Language:
   # TITAN
   cd titan_compiler && cargo run -- run ../examples/hello_world.titan
   
   # SYLVA
   cd sylva_compiler && cargo run -- run ../examples/neural_network.sylva
   
   # AETHER
   cd aether_compiler && cargo run -- run ../examples/distributed_system.aether
   
   # AXIOM
   cd axiom_compiler && cargo run -- prove "add_commutative"

3. Launch Interactive REPL:
   # For any language
   cd <language>_compiler
   cargo run -- repl

4. Run Complete Test Suite:
   bash test_all_languages.sh
